Disconnecting GitHub or restarting the browser retains captured source, pending delivery jobs, and saved history. Retained jobs stay bound to their original GitHub account, App, installation, repository, and branch. Reconnecting or changing the selected destination does not resume or redirect these jobs automatically.

Reconnect with the original account and App, then select and verify the original destination before choosing “Check GitHub and retry delivery”. Requests already issued may complete even after disconnect.

“Discard local attempt” removes an unsaved attempt's captured source and delivery job only from this browser. This cannot be undone and does not delete anything on GitHub or prove that publication never happened. Saved receipts are not discardable here.
