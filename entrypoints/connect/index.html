Only the expiring access token is retained in trusted browser-session storage. Refresh tokens are discarded. Reconnect after browser restart or token expiry.

Disconnecting and retained work

Disconnect clears local credentials. Disconnecting or restarting the browser retains captured source, pending delivery jobs, and saved history. Each delivery job stays bound to its original GitHub account, App, installation, repository, and branch; a different account or destination cannot take it over.

Reconnect with the original account and App, then select and verify the original destination before explicitly checking GitHub and retrying a retained job. Reconnecting does not resume these jobs automatically.

Requests already issued may still complete after disconnect. Disconnecting or discarding local work does not delete repositories, files, or commits on GitHub, and does not prove that publication never happened.

Disconnect does not revoke GitHub-side App authorization or uninstall the App. To change GitHub-side access:

  • Authorized GitHub Apps — revoke authorization
  • Installed GitHub Apps — manage installation
